# 為替相場の見方・特徴と実践戦略まとめ

【ドル安10年時代】これから10年ドルが下がり続けるとゴールドが上がる？ドルの行き先と為替の見方・視点を解説

---

## 1. 為替の基本的な見方（グローバルマクロの視点）

為替は参加者（個人・機関・国家）の種類も動機も非常に多く、理論通りに動かないことが多いため、株式以上に予想が難しい市場だと前置きしたうえで、それでも押さえておくべき基本フレームワークとして次の5つを挙る。

**実質金利差**：教科書的には、金利の低い通貨から高い通貨へ資金が流れるため、為替は2国間の実質金利差（名目金利－期待インフレ率、代替指標として10年債利回り－CPI）で決まるとされる。重要なのは実質金利差の絶対値だけでなく、その差が拡大しているか縮小しているかという方向性も見る必要がある点。

**中央銀行の金融政策の方向性**：タカ派（利上げ・引き締め）かハト派（利下げ・緩和）かという政策スタンスの違いが通貨に影響する。実際の利上げ・利下げだけでなく、FOMCやECB理事会、日銀金融政策決定会合後の総裁発言やステートメントの文言から、市場は将来の金利動向を先回りして織り込むため、そうした発言内容も注視すべき。

**貿易収支・経常収支（フロー要因）**：輸出企業は受け取った外貨を売って自国通貨を買うため、貿易黒字国の通貨は上昇しやすい。日本については、デジタル赤字（海外企業へのサービス支払い）やエネルギー輸入がドル建てで行われることから、構造的に円売り・ドル買いが発生しやすく、為替介入をしても円高になりにくい背景がある。

**購買力平価（PPP）とインフレ格差**：同一財の価格は世界で等しくなるはずという一物一価の考え方に基づく理論。インフレ率が高い通貨ほど購買力は低下する。短期的には金利差に負けることもあるが、行き過ぎた相場は歴史的に平均回帰する傾向がある。現在の円安水準はPPP（購買力平価）で見ると80〜100円程度が妥当とされ、実勢との乖離が「異常な水準」にある。

**地政学リスクとリスクオン・オフ**：不確実性が急拡大する局面（軍事衝突など）では、依然として世界の資金はまずドルに逃避する傾向が強い。かつては「安全資産としての円」という見方もあったが、対外純資産の多さを根拠にしたこの説明は、実際に円安が進行している現状とは整合しない。

## 2. 各通貨ペアの特徴

| 通貨ペア | 主な特徴・注目点 |
|---|---|
| **ドル円** | 日米の金利差にある程度連動。米10年債利回りと日本の長期金利をチェック。近年は円安局面で政府・日銀の為替介入が入るため、上値が重くなりやすい。 |
| **ユーロドル** | 世界最大の取引量を誇る通貨ペア。一度トレンドが出ると継続しやすい特徴。FRBとECBの政策差、欧州（特にドイツ）のエネルギー問題・ウクライナ情勢などの地政学リスクが影響。 |
| **ポンドドル** | イングランド銀行（BOE）は歴史的にインフレに対しタカ派で、本来ポンドは強含みやすい通貨だが、近年はイギリスの政治不安（首相交代の頻発など）も重なり弱含み。経済規模自体も日本の半分以下と縮小傾向。 |
| **豪ドル** | 鉄鉱石・石炭・天然ガスなど資源輸出への依存度が高い「コモディティ通貨」。資源価格上昇時に上がりやすい。中国経済（景気・不動産・インフラ投資）との連動性が強い。RBA（豪準備銀行）はインフレに敏感に反応する中央銀行。 |
| **ドル指数** | ユーロ・円・ポンドなどをバスケット化し、個別通貨・国別要因を排除してドル全体の強弱を示す指数。 |
| **新興国通貨**（南アフリカランド、トルコリラ、メキシコペソ、ブラジルレアルなど） | ボラティリティが極端に高い。政情不安を背景に金利が高く、スワップ狙いの取引が人気だが、逆転して急落するリスクも大きい（例：トルコリラ）。米金利水準との比較、経常収支・外貨準備、実質金利、中央銀行の独立性（政府による政策介入の有無）が鍵。 |

## 3. 「理論通りに動かない」現実

実質金利差モデルで計算すると、現在のドル円の理論値は100円前後とされるが、実際の相場は160円近辺で推移しており、理論値からかなり乖離した「異常な円安」状態にあると江守氏は指摘する。一方でユーロドルは比較的理論通りに動いており、世界で最も取引される通貨ペアであるがゆえに市場参加者の合意形成が価格に反映されやすいのではないか（ポンドや豪ドルも対ドルで見るとやや割安との分析）。

---

## 4. ドルの長期サイクル分析

ドルは概ね7年周期で変動しており（一部9年・14年という例外もあり）、直近の上昇は2022年にピークをつけたとみられる。7年下落サイクルなら2029年頃、14年下落サイクルなら2036年頃がドルの底値候補になる。

さらにドル円独自のサイクルとして、通常は「3年上昇・5年下落」を繰り返す傾向があったが、今回は上昇局面が異例の6年に及んだ（2026年6月に一度高値をつけた後、それを更新）。上昇期間が通常の2倍になった場合、下落期間も通常の2倍（5年→10年）になる可能性があるとし、2026年から2036年までドル安局面が続くという仮説を提示できる。

このシナリオが実現すると、**ドル指数の下落＝ゴールド（金）の上昇**という構図になりやすいという見立て。

## 5. 実践的な投資戦略

**ドル円**：介入リスクがあるため単純な逆張りは避け、「引きつけてから少し買い、上がったらすぐ売る」短期的なレンジ対応を推奨。160円を超えたら戻り売り、割れたら買いというイメージ。米国が日銀に利上げ圧力をかける一方、政権が利上げに慎重という綱引きがあり、日米金利差が縮小すれば円高方向に傾きやすい。

**ユーロドル**：ユーロ単体よりもドル全体の方向性で見た方がよい。現状はまだドル買いフローが強くユーロは上がりにくいが、ドル買いの流れが転換すれば最も上昇しやすい通貨の一つであり、その際は順張り（トレンドフォロー）が有効。

**ポンドドル**：インフレ動向とBOEの利上げ・利下げ判断に連動しやすく、こちらも順張りが基本。

**ユーロポンド（クロス通貨）**：ボラティリティは比較的低めながら、トレンドが出ると大きく動く通貨ペアで、FXトレードとしてリターンを出しやすいとの経験談。金利差からユーロ売り・ポンド買いのキャリー取引が有利になる局面が多い。

**豪ドル**：世界景気や中国経済との連動性に加え、コモディティ通貨としての側面が強い。ドル安局面ではコモディティ価格が上がりやすく、リスクオン局面での資源高が豪ドル高につながりやすい。

---

## 6. まとめ

為替は関与するプレイヤーが多く、単一の要因では説明しきれないため予想は本質的に難しい。しかし、実質金利差・金融政策の方向性・貿易収支・購買力平価・地政学リスクという基本フレームワークを押さえたうえで、長期サイクル（ドルは7〜14年、ドル円は独自の周期性）を意識することで、為替だけでなく金利やコモディティ、ひいてはゴールドの投資判断にも応用できる視点が得られる、というのが動画全体の結論。トレードの実践においては理論に固執しすぎず、テクニカルも併用した柔軟な対応が推奨される。
