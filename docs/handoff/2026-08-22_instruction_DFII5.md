## 0. この指示書の性格

**前回のバックフィルで 8-2 は「破棄行」を回避した。** 8/4のBEは実際に -4.0bp 落ちていた。

**しかしそれは必要条件であって、機構の確認ではない。**

8-2 が主張しているのは **実質金利** の話：

> ドル安だけでは足りない。**BEが崩れているから実質金利が下がらず**、金に来ない。

```
Δ実質 = Δ名目 − ΔBE
ΔBE = −4.0bp（実測済み）
Δ名目 = 未測定  →  Δ実質の符号が決まらない
```

**Δ名目が -4bp なら実質は横ばい**（8-2成立）。**-10bp なら実質は -6bp** で、金は上がるはずだった（8-2は機構として失敗）。

★ 前回の分岐表が「BEが落ちたか/平坦か」の二択だったのは、**量の問題を有無の問題として書いていた**ため。設計側の不備であり、
**-4.0bp という測定値の解釈を事後に変えているのではない**。生存判定は登録どおり通したうえで、機構の確認を別に行う。

## 1. なぜ DFII5 か

FREDの定義上、

```
T5YIE  =  DGS5  −  DFII5
（5年BE） （5年名目CMT）（5年TIPS＝実質）
```

**`DFII5` が実質金利そのもの。** 推定も差分計算も要らない。

さらに **3系列すべてを取れば恒等式が成り立つかを検算できる** → 「正しい系列を引けているか」の最強のサニティチェックになる。
（前回、代理指標を2回立てて2回とも棄却された経緯がある。本体を直接取り、かつ検算する）

## 2. 実装

### 2-1. `FRED_SERIES` に2本追加（`configs/settings.py`）

```python
FRED_SERIES = {
    "US5YBE":    "T5YIE",    # 既存
    "US5Y5YBE":  "T5YIFR",   # 既存
    "US5YREAL":  "DFII5",    # 追加：5年TIPS利回り＝実質金利
    "US5YNOM":   "DGS5",     # 追加：5年名目CMT（FRED）
}
```

### ★ 2-2. `DGS5` を既存の `US5Y`（`^FVX`）と統合しないこと

**これは最優先の禁止事項。**

| ラベル | ソース | 性質 |
|---|---|---|
| `US5Y` | Yahoo `^FVX` | 既存。取得タイミングは実行時 |
| **`US5YNOM`** | **FRED `DGS5`** | **NY引け基準・日次・公表ラグあり** |

**同じ「5年名目金利」だが、フィードも時刻も異なる。** 1本の系列に混ぜた瞬間、
**変化の大半が時刻差になる**（日次変動が1〜3bpの指標では致命的）。

★ **`settings.py` に「`US5YNOM`(DGS5) は `US5Y`(^FVX) とは別フィード。統合・置換しないこと」というコメントを必ず添える。**
命名の原則（代用品には本物の名前を付けない／欠損は気づかれるが間違った値は気づかれない）に従う。

## 3. ★ 事前登録した判定分岐（取得前に確定・変更禁止）

### 3-1. 年輪8-2 の機構確認 — 判定対象は **8/3 → 8/4 の ΔDFII5**

**8/4は「DXYが99.527を割った（ドル安）のに金が動かなかった」日。**

| 8/3→8/4 の ΔDFII5（実質金利） | 8-2の帰結 |
|---|---|
| **0bp 以上**（上昇 or 横ばい） | ★**8-2の機構が確認される。** BEの低下が名目の低下を打ち消し、実質金利は下がっていなかった。金の非反応は説明がつく |
| **-3bp 以下**（明確に低下） | ★**8-2は機構として失敗。** 実質金利は下がっていたのに金は動かなかった。**BEでは説明できない** → 需給/ポジションの偏りなど別系統へ |
| **-3bp 超 0bp 未満**（-2 / -1bp） | **判定不能・保留。** どちらにも寄せない |

★**中間帯を「弱い低下だから失敗寄り」などと読まない。** 保留は保留として記録する。

### 3-2. 年輪8-3 第2段の検証 — 判定対象は **8/4 → 8/5 の ΔDFII5**

8-3の主張：

> 1. BEだけ下がる段階 → 実質金利↑ → 金にマイナス（8/3-8/4）
> 2. 政策パス自体が下がる段階 → **名目がBEより下がる** → 実質金利↓ → 金にプラス（8/5）

**8/5のΔBEは -1.0bp しか動いていない**（実測済み）。第2段が正しければ、名目が大きく下がって実質が落ちているはず。

| 8/4→8/5 の ΔDFII5 | 8-3 第2段 |
|---|---|
| **-3bp 以下** | ★**第2段が実測で裏づく** |
| **0bp 以上** | ★**第2段は成立しない。** 8-3の定式は要再検討 |
| 中間 | **保留** |

### 3-3. 8-3 第1段（参考・判定には使わない）

`7/31 → 8/4` の **累積 ΔDFII5 が正**であれば第1段（実質金利↑）と整合。**診断としてのみ記録。**

## 8. ★ 下流でやること（ClaudeCodeの作業範囲外・記録のため）

**8-2「ドル安 かつ BEが崩れないこと」は許容条件（negative condition）であり、反証しにくい。**

BEが横ばいでも「崩れていない」ので条件は満たされる。実際 **8/19（BE +1.0bp・金 +4.80%）は文言上8-2に整合する**——
BEが説明力をまったく持たずに金が4.8%動いた事例であるにもかかわらず。

★ **DFII5が入れば、条件を「BEが崩れないこと」から「Δ実質金利が下がること」へ書き換えられる。**
符号で判定できる形になり、反証可能になる。**この書き換えはRex側で行う。ClaudeCodeは数値まで。**
