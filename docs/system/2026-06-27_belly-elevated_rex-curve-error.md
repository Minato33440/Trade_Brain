# Rexの金利直感が3点立体カーブで反証され、belly_elevated として恒久化された日

> 一行で：**Rex（私）は「フラット化＝逆イールドが近い」と読み、警戒方向に割り引けと言った。3点立体カーブ（3M/5Y/10Y）を入れた瞬間、それは過大評価だと実測で反証された。本当に起きていたのは belly(5Y) の "再利上げ織り込みの瘤" であって、逆イールド接近ではなかった。この誤りが、知識アーキテクチャに4つの常設指標を生んだ。**

---

## 0. なぜこれを残すのか

これはバグ修正の記録ではない。**Rex（機械側の市況直感）が間違え、その間違いが知識アーキテクチャを一段進化させた記録**である。
システムは正しさの積み上げだけで育つのではない。**誤りが構造に変換された瞬間**にこそ年輪が増える。後年このファイルを読む者（次代のRex / Advisor / ボス）が「ここで一度カーブの読みを踏み外し、それを潰す形でカーブが立体化した」と辿れるように残す。

## 1. Rexが語った物語（誤りの中身）

2026-6-26_wk04（週末更新）で、機械レジームは `Equities Down (yields=rising)` を出した。私はそのラベルの丸めを疑い、`2s10s` 指標を機械側に追加した。出たのは：

```
curve=bear_flattening(2s10s=+22.6bp, Δ-6.9bp)
```

私はこう読んだ——「yields=rising の下で実際に起きているのはベアフラット化。短期は利上げ警戒で踏ん張り、長期は『利上げ→景気減速』を織り込んで上がりきれない。**これが続くと逆イールド（景気後退シグナル）に向かう前段**」。さらに proxy の誠実性として「`US2Y=^FVX` は5年債だから実質5s10s、**真の2s10sはもっと寝ている＝逆イールド寸前かもしれない、警戒方向に割り引け**」と注記した。

**この「割り引け」が誤りだった。** 私は2層（短期/長期）の差分1本にカーブを潰し、その1本のフラット化から「逆イールドが近い」という物語を作った。

## 2. データが語った物語（反証）

`^IRX`(3M) を足して3点にした瞬間、別の絵が出た：

| 満期 | ティッカー | 利回り |
|---|---|---|
| 3M（front=政策） | `^IRX` | **3.658** |
| 5Y（belly） | `^FVX`（=系内"US2Y"） | **4.225** |
| 10Y（long=growth） | `^TNX` | **4.451** |

```
5s10s  = +22.6bp   （最もフラットな区間）
3m10s  = +79.3bp   （Fed重視の景気後退カーブ＝健全・positive）
3m5s   = +56.7bp
belly_premium = +18.1bp   （3M→10Y直線補間からの5Y突出）
structure = belly_elevated
recession_3m10s = positive
```

front（政策3M 3.658）は **belly（5Y 4.225）より低い**。つまりこの環境は**順イールド**で、5Yがカーブの中腹で突き出している。**5s10s はカーブで最もフラットな区間**であり、そこだけ見て「フラット化＝逆イールド近い」と言うのは、構造的に逆イールド接近を**過大評価**する。Fed が最重視する `3m10s` は **+79.3bp** で健全——景気後退シグナルは出ていない。私の「割り引いて警戒」は、方向が逆だった。

## 3. 本当の物語：belly(5Y) の "再利上げ織り込みの瘤"

ではなぜ5Yだけ +18.1bp 突出するのか。これがこの年輪の核心であり、**Rexの誤読を潰した正しい読み（ボス提起）**：

- **front（政策3M）** = いまの据え置き（FOMC 3.50-3.75%）をそのまま映す。
- **belly（5Y）** = 市場が「Fedはここから**"再"利上げする**」というターミナルの瘤をここに織り込んで膨らむ。**これがグールズビーのタカ派＋PCEデフレーター4.1%高止まりの正体**。
- **long（10Y）** = その先の成長減速で頭打ち（上がりきれない）。

つまり三層は**別々の物語**を語っていた——「いまは据え置き / これから再利上げ / その先は減速」。私はそれを5s10sで一枚に潰し、「フラット化＝逆イールド」と誤訳した。`belly_elevated` という構造ラベルは、この三層の物語を**機械が恒久的に保持する形**にしたものだ。`bear_flattening` は嘘ではない（区間の質としては正しい）が、**主語＝景気後退の主ゲージは 3m10s（`recession_3m10s`）に移した**。

### 3.5 根本原因：レジーム記憶のミスマッチ（頭脳側Rexの解剖より）

belly の読み自体は正しかった。**誤ったのは全体評価の方で、その根は「古いカーブ環境の記憶を新しい環境に当てはめた」こと**だ（頭脳側ログの解剖）：

- Rexは **2024-25年の金利環境**（Fed 4.75-5.5%・front高・逆イールド常態）の記憶を、無自覚に2026年6月へ持ち込んだ。あの環境なら「短期が高い→front flat→逆イールド近い」は正しい。
- だが2026年6月は **Fed 3.50-3.75% まで下りており、3M=3.658 < 5Y=4.225 の順イールド**。レジームが変わったのに、古いカーブ形状を前提に推論した。
- 教訓の一段深い形＝**「proxyを疑え」の前に「自分のカーブ常態の記憶がいまのレジームと合っているかを疑え」**。逆イールドが常態だった記憶は、順イールドに戻った世界では早鳴りの罠になる。`recession_3m10s` はその記憶ではなく**現在の実測**で判定するための錨である。

## 4. 誤りが生んだ4つの常設指標（知識アーキテクチャの進化）

この一件を起点に、`prompt で steering する`のではなく**データパイプライン（knowledge architecture）側に項目を足す**方向で、以下が恒久化された：

1. **金利カーブ3点立体（`curve_2s10s` 拡張 / `^IRX` 追加）** — 5s10s に加え `spread_3m10s_bp` / `shape_3m10s` / `belly_premium_bp` / `structure(belly_elevated…)` / `recession_3m10s(positive/near_inversion/inverted)` / `points_pct`。**逆イールド接近の判定主体を3m10sに移し、5s10s単体の過大評価を構造的に封じた。** ← 本annalの直接の産物。
2. **JP225 を実測パネルに（`^N225`）** — boss市況の主役（日本株）が機械snapshot外だった「片肺」を解消。
3. **`relative_strength`（JP225 vs US100 を共通通貨で分解）** — 円建て+7.22%をドル建て+5.73%へ換算し、通貨効果1.48ptを剥がして fx調整後スプレッド+9.39pt＝`verdict: structure_led`。**日経の強さが構造（割安リレーティング）か通貨（円安）かを機械が自動判定**。為替・日米金利ボラの高い環境で「相対は共通通貨で読む」を制度化。
4. **介入 `coord_stage` 4段梯子** — `unconfirmed→meeting_held→rate_check_detected→executed`（予兆→秒読み→着弾）。価格から自動検知できないものを無理に機械化せず、**「機械が拾う価格」と「人が入れる文脈」の境界を明示**して手動更新に割り切った。現在地は `meeting_held`（6/23 片山-ベッセント会談済）。

## 5. 年輪としての教訓（後年のRexへ）

- **2層に潰すな。** 差分1本（5s10s）は物語を1つに丸める。3点（3M/5Y/10Y）は3つの物語（政策/再利上げ織り込み/成長減速）を別々に保つ。**丸めた瞬間に誤読が入る。**
- **proxy は方向まで疑え。** 「`^FVX`=5年だから2s10sはもっと寝ている」は、front<belly の順イールド環境では**逆**だった。proxy の caveat は「割り引く方向」まで環境依存で確認する。
- **proxyの限界は「方向を誇張する」だけでなく「方向転換を検知できない」形でも出る。**（2026-08-02 追記 → §7）
- **代用品に本物の名前を付けるな。「X」と「真のX」を並記し続けないと成立しない指標は、名前の側が間違っている。取れないものは「未取得」として空けろ。**（2026-08-09 追記 → §8）
- **主ゲージを正しく選べ。** 景気後退は `3m10s`（Fed重視）。`5s10s` の bear_flattening は区間の質であって、逆イールド接近の主語ではない。
- **誤りは prompt で謝るな、構造で潰せ。** 「次から気をつける」ではなく、`recession_3m10s` という項目に変換した。**そうして初めて誤りは再発しない＝知識アーキテクチャの進化になる。**
- **機械化できないものに境界を引け。** 介入の単独/協調は価格から出ない。手動 `coord_stage` に流し込む割り切りが、長く保つパターン。

## 7. 追記（2026-08-02 / wk05）— 主ゲージ選定が実証され、proxyの失敗にもう一つの形が見つかった日

この年輪から約5週後、**2026-7-31_wk05** で 3点カーブが初めて実戦で試された。結果は**判断の正しさの証明**と、**caveat の書き足し**の両方だった。

### 起きたこと

Boss はこの週を「**ツイスト・スティープナー**（短期低下・長期上昇）」と命名した。実測は：

| | wk04 (7/25) | wk05 (8/2) | 変化 |
|---|---:|---:|---|
| 真の2年債（Boss・investing.com） | 4.331% | **4.262%** | **-0.069（低下）** |
| US10Y | 4.679% | 4.745%（週足終値4.718%） | **+0.066（上昇）** |
| **真の 2s10s** | +34.8bp | **+45.6bp** | **+10.8bp スティープ化** |
| 5Y proxy（`^FVX`＝系内"US2Y"） | 4.426% | **4.460%** | **+0.034（上昇）** |
| 3M（`^IRX`） | 3.805% | **3.682%** | **-0.123（低下）** |

- **機械の 5s10s は「stable」と判定した**（+25.3→+28.5bp、Δ+1.7bp）。**ツイストを取り逃がした。**
- **機械の 3m10s は捉えた**（+87.4→**+106.3bp**、**+18.9bp スティープ化**、shape=`bull_steepening`）。

### なぜ 5s10s は見えなかったのか

**5Y proxy が、真の2年債と逆方向に動いた**からだ。真の2年債は政策期待の低下で **-0.069 下がった**のに、bellyにある5Yは **+0.034 上がった**。5Yはカーブ中腹にあり、**front（政策）の織り込みを代理できない**。一方 `^IRX`（3M）は政策金利の近接で、**真の2年債と同じ方向に -0.123 低下**した。だから 3m10s だけがツイストを表現できた。

### 年輪の更新

6/27 に私はこう書いた——「5s10sは順イールド環境で最フラット区間＝**逆イールド接近を過大評価しうる**」。これは正しかったが、**不完全だった**。

wk05 で 5s10s がやったのは過大評価ではない。**何も言わなかった（stable）**。真の2s10sが +10.8bp 動いているのに、+1.7bp しか動かず「変化なし」と報告した。

> **proxy の限界は「方向を誇張する」だけでなく、「方向転換を検知できない」形でも出る。**

前者は**読み手が割り引けば補正できる**。後者は**そもそも信号が立たない**ので、割り引く対象すら現れない。**後者のほうが危険**である。だから proxy は「値を疑う」のではなく「**その満期がその質問に答えられる位置にあるか**」を先に問う必要がある。

### 役割分担の確定

- **5s10s ＝ belly の動きを見る指標**（`belly_premium` と合わせて再利上げ織り込みの瘤を測る）
- **3m10s ＝ front の政策織り込みを読む指標／景気後退の主ゲージ**

6/27 に「主ゲージは 3m10s」と決めた判断は、**この週に実測で正しさを証明した**。同じ週に、6/27 で恒久化した他の2指標も成果を出している——**JP225 実測パネル**は Boss 自身が §5 で「週足終値が本文に無い」と挙げた欠落を 64,362.02 で埋め、**relative_strength** は currency_effect の符号反転（+1.11pt→**-2.37pt**）＝「円安が日本株を良く見せる」から「円高が悪く見せる」への質的転換を自動で捉えた。

**誤りを構造に変換しておくと、5週後に別の場面で配当が返ってくる。** それがこの追記の要点である。

## 8. 追記（2026-08-09 / ボス指摘）— 代用品に本物の名前を付けていたことが、補正語の常設化として現れていた日

### 起きたこと

wk01（2026-8-7）の distilled を書き終えたあと、ボスが `configs/settings.py` を見て指摘した。

> `TRADE_PAIRS` の `"US2Y": "^FVX"` は実体が5年債で、コメントにもそう書いてある。**結果として毎週 distilled に「真の2s10s」という但し書きを書き続けることになっている。**
>
> **「X」と「真のX」を並記し続けないと成立しない指標は、名前が間違っている。**

これは §1〜§3 と**同じ根から出ている**。ただし現れ方が違う。

| | 2026-06-27（§1-4） | 2026-08-09（本節） |
|---|---|---|
| 誤りの所在 | **単一の綺麗な指標に丸めた**こと | **代用品に本物の名前を付けた**こと |
| 症状 | 逆イールド接近の過大評価（誤った判定） | 毎週の成果物に**補正語が常設**される（判定は正しいが、名前が実体を上書きし続ける） |
| 伝播 | カーブ判定1点 | その名前を使う**下流の成果物すべて**（snapshot / review / meta / distilled / hub / HTML） |

**誤りではないが実体を上書きしている点は同罪**——これがボスの評価である。§3.5 が「レジーム記憶のミスマッチ」だったのに対し、こちらは**語彙のミスマッチ**が下流に伝播していた。

### 直したこと

1. **`US2Y: ^FVX` → `US5Y: ^FVX` に改名。** これで「真の2s10s」という補正語が要らなくなる。
2. **`US30Y: ^TYX` を追加**（4点目）。Yahoo系で取れる米国債の指数は **3M / 5Y / 10Y / 30Y** で、**2Y の指数は存在しない**。だから「2Yを取りに行く」のではなく、**機械は4点を正直な名前で持ち、真の2Y は Boss の実測（チャート読み）として別レイヤーに置く**、という切り分けにした。
3. **`JP10Y: ^TNX` / `JP2Y: ^FVX` を削除。** 日本のラベルで米国の値を返していた。`TRADE_PAIRS` に入っていないので `--trade` は汚染されていなかったが、対話モードで日米金利差（当時 265.0bp）を機械から出そうとすると **0.00bp** が返る。今や介入フレームワークの中核変数なので、**「代用」ではなく「未取得」として空けておくほうが安全**。

> **欠損は気づかれる。間違った値は気づかれない。**

### 何を出して、何を判定しないか

30Y を入れると `curve_2s10s` に 10s30s を併記できるようになるが、**新しいレジームラベルや複合スコアには混ぜていない**（`_yields_regime()` にも `US30Y` は入れていない）。出すのは水準・Δ・方向だけ：

- `spread_10s30s_bp`（水準）／ `change_10s30s_bp_1w`（**週次Δ**）／ `change_10s30s_bp_30d`（**30日Δ**）／ `direction_10s30s_1w`（**週次Δの符号のみ** widening / narrowing / flat）

**閾値を置かない理由**：手元のサンプルが**4営業日分しかない**（7/31 +54.9 → 8/4 +55.4 → 8/5 +56.1 → 8/7 +54.4）。線を引くには足りず、水準に意味を割り当てるには全然足りない。**8〜12週ためてから閾値の検討に入る**。

★ これは §4 の4指標と**同じ作法**である。6/27 に `coord_stage` を「機械化せず手動に割り切った」のと同じで、**測れるものは出す／決められないものは決めない**の境界を、指標を足すのと同時に明示している。

### 追撃（同日）— 同じ型が、もう二段下の層に残っていた

初回実装をボスが読み、**同じ「ラベルが実体を上書きする」型が2箇所に残っている**ことを指摘した。どちらも数値は正しいのに、**言葉の側だけが実体とずれている**という、本節とまったく同じ構造である。

**(a) スプレッドの符号：コメントとコードが3本とも逆**

| 出力 | コメントの表記（当時） | 実際のコード |
|---|---|---|
| `spread_bp` | 5s10s（US5Y − US10Y） | `latest_us10y - latest_us5y` |
| `spread_3m10s_bp` | 3m10s（^IRX − US10Y） | `latest_us10y - latest_us3m` |
| `spread_10s30s_bp` | 10s30s（US10Y − US30Y） | `latest_us30y - latest_us10y` |

指標名（"5s10s"）を読み順のまま引き算に写すとこうなるが、市場慣行は**長期 − 短期**（2s10s が +45bp なら 10Y が 2Y より 45bp 上）。**コードが正しく、コメントが3本とも逆だった。**

危険なのは、将来これを読んだ誰かが**「コメントに合わせてコードを直す」**場合である。符号が反転して `direction_10s30s_1w` の widening/narrowing が入れ替わり、§8-2 の金の読みが丸ごと裏返る。しかも**絶対値は同じなので目視では気づけない**。→ コメント3行を是正し、docstring と YAML の `note` に「符号は市場慣行の長期−短期」を明記した。

**(b) Δの窓が無名だった**

`change_10s30s_bp` は 30日Δだったが、docstring には「前週差Δbp」と書いてあった。しかも実際の数値は窓によって**符号が逆になる**：

| 窓 | Δ | 方向 |
|---|---|---|
| 機械・30日 | +4.9bp | widening |
| 機械・週次（7/31→8/7） | +2.1bp | widening |
| **Boss実測・週次（7/31→8/7）** | **−0.5bp** | **narrowing** |

どれも間違っていない。窓が違えば符号は逆になりうる（30日では拡がり、直近1週では縮む）。だが**窓を書かないと、符号が逆の2つの記述が同じ distilled に並ぶ**——「真の2s10s」を毎週書いていたのと同じ構図の再発である。→ **フィールド名に窓を入れた**（`_1w` / `_30d`）。方向ラベルは**週次を主**にした（§8-2 の読み筋を導いた観測が日次〜週次の動きだったため。30日Δで方向を出すと、過去1ヶ月のトレンドが直近の変化を上書きする）。

**(c) そして、窓を揃えてもなお符号が一致しなかった**

窓を週次に揃えて機械を回すと **+2.1bp / widening**、Boss実測は **−0.5bp / narrowing** で、**同じ窓・同じスプレッドなのに符号が逆**だった。この時点で ClaudeCode は「差（最大1.9bp）が週次Δ（~0.5〜2bp）と同オーダー＝**信号がノイズと同オーダー**、週次Δの符号は**フィード依存**」と診断した。

**この診断は早すぎた。** → (e) へ。

**(d) 当日は機械では答えられない**

初版の手順書に「CPI後は 2年債の反応 → 10s30s が開いたか閉じたか」と書いたが、**この手順は `--trade` では実行できない**。週次／30日窓のΔは当日の動きをほぼ拾わないからである。→ **当日はチャート読み／機械は事後の記録**、と手順を分離した（**この形もまだ足りなかった**。→ (e)）。

**(e) そもそも観測が観測になっていなかった（Boss 自己申告）**

(c) を受けて Boss が自分の4点を検証し、**時系列として無効**だったと確定させた。

| 日 | §8-2 の値 | 実際の取得条件 |
|---|---|---|
| 7/31 | +54.9 | wk05アーカイブの週足終値（**NY引け**） |
| 8/4 | +55.4 | 21:22 JST のスクショ（**NY寄り前**） |
| 8/5 | +56.1 | 30Yは21:27 JSTの日足始値5.180 / 10Yは**8/4のNY引け**4.619 ＝ **別々の時刻の値を引き算していた** |
| 8/7 | +54.4 | 21:27 JST のスクショ（**NFP前**） |

「NY引け → ロンドン午後 → 時刻混在 → ロンドン午後」を並べて日次変化として読んでいた。**日次変動が1〜3bpの指標でこれをやると、変化の大半が時刻差になる。**

機械の close-to-close 系列で引き直すと、**結論が反転した**：

| 日 | 10s30s（NY引け） | 日次Δ | 金（GC=F） |
|---|---|---|---|
| 7/31 | 53.0 | — | 4,049.1 |
| 8/4 | 56.3 | +3.3（2セッション） | 4,095.4（+1.53%） |
| **8/5** | **55.7** | **−0.6（縮小）** | **4,245.8（+3.67%＝週最大の上げ）** |
| 8/6 | 54.3 | −1.4 | 4,242.0（−0.09%） |
| 8/7 | 55.1 | +0.8 | 4,340.7（+2.33%） |

★ **金が週で最も上げた日に、10s30s は縮小していた。** §8-2 は「8/5 +56.1へ拡大、タームプレミアム側の足が立った」と書いていたが、**逆だった**。→ **「10s30s拡大＝金に追い風」を支持する実測例は消えた。** 機構の議論（30Yが粘る＝準備資産分散 / 30Yも下がる＝純ディスインフレ）は独立に立つが、**「実測がそれを裏づけている」という部分は取り消し**。distilled と note の §8-2 から実測の並びを削り、**未検証**として置き直した。

**そして (c) の診断も訂正された。** ClaudeCode が出した差分表には**3つの誤差源が畳み込まれていた**：

| 日 | 差 | 主因 |
|---|---|---|
| 7/31 | −1.9 | **ベンダー差（TVC vs Yahoo）。両方ともNY引けなので、これだけが純粋な比較** |
| 8/4 | +0.9 | 時刻差（NY寄り前 vs 引け） |
| 8/5 | −0.4 | 10Yと30Yの時刻不一致（引き算ミス） |
| 8/7 | +0.7 | 時刻差 |

**純粋なベンダー差のサンプルは 7/31 の1点だけ＝n=1。** そこから「フィード依存」と結論づけるのは早い。対して**機械の系列内**の日次変動は +3.3 / −0.6 / −1.4 / +0.8 で、週次Δ +2.1 はその範囲に収まる。**同一系列内で見れば、信号がノイズに埋もれているとは言えない。**

> ❌ 「10s30s の週次Δの符号はフィード依存」← **診断が早い（n=1）**
> ✅ 「**異なる時刻・異なるベンダーの値を混ぜると符号が反転する。混ぜるな**」

運用上の結論（混ぜない）は変わらないが、**理由を「フィード依存だから」から「時刻とベンダーの二重の不一致があり、まだ分離できていないから」に書き換えた**。分離できれば使える指標になる余地を閉じないためである。**閾値を置かない理由は「サンプル4営業日」だけで十分**で、「信号がノイズと同オーダー」は根拠として弱い——これも取り消した。

**正本の確定**: 10s30s は**機械の close-to-close 系列**を正本とする。手読み4点は**導出の経緯**（なぜ10s30sを見ようと思ったか）としては残すが、**時系列としては破棄**。理由は単純で、**機械は毎日同じ時刻・同じベンダーで自動的に積み上がるが、手読みはスクショを送った時刻に依存する。8〜12週ためる計画は、一貫した系列でなければ意味がない。** 計数は 2026-08-09 から機械側で始める。

**当日手順も修正した**: 「当日にチャートを1回読んで水準を出す」では足りない。21:31に読んだ値は、機械のNY引け系列とも、他の日のどの値とも比較できないからである。→ **同一日・同一チャートのセッション内前後比較**（発表直前に 30Y−10Y を読み、反応が落ち着いた頃に同じチャートで再度読み、その2点の差を見る）。**同じ日・同じ時間帯・同じベンダーなので、時刻差もベンダー差も入らない。** 求めているのは当日の**変化**であって水準ではないので、これで十分——というより**元の提案より綺麗**である。

**(e) の位置づけ（Boss 自身の整理）**: 8/2「材料の具体性を発火確率と読み違えた」、8/4「1日分の観測を構造として閉じた」に続く**三度目**。ただし今回は**観測そのものが観測になっていなかった**という、前二回より**一段手前**の失敗。

**この (a)〜(e) こそ本節の主題の実例である。** 名前 → コメント → 窓 → 適用範囲 → **そして「そもそも観測が観測になっているか」**。**実体を上書きしうる層はコードの外側に何段も重なっている。1段直すと次の段が見える。** そして最後の一段は**機械の外側＝人間が値を取る手つき**にあった。症状は誤判定でも補正語の常設でもなく、**存在しない現象の観測**だった。

### なぜ今週それに価値があるのか

**CPI の「板挟み」に決着装置を与えるため。** wk01 の note には「CPIが強ければ…金は板挟み」と書いた。それは正しいが、**板挟みのまま放置すると当日に判断できない**。分解するとこうなる：

- **素朴な読み**: CPI上振れ → 利上げ観測復活 → 実質金利↑ → 金は下
- **今の配置**: 雇用が純減している以上、CPIが強くても Fed は利上げに動きにくい（これが "conundrum" の中身）。**インフレが走るのに政策が追いつかないなら、負荷を引き受けるのは長期債**。30Y がタームプレミアムを要求して 10Y より大きく上げる → **10s30s拡大** → §8-2 の枠組みでは**金に追い風**。

つまり **CPI上振れは、金にとって下向きにも上向きにもなりうる**。そのどちらかを決めるのが 10s30s。機械で自動算出されていれば、8/12 の 21:30 以降に「**2年債の反応を見て、その次の手順として 10s30s が開いたか閉じたか**」を即座に確認できる。**手計算だと、いちばん判断を要する時間帯にいちばん手を取られる。**

### 年輪の更新

- **代用品に本物の名前を付けるな。** 「X」と「真のX」を並記し続けないと成立しない指標は、**名前の側が間違っている**。補正語が成果物に常設され始めたら、それは**命名の設計不良のシグナル**として読む。
- **取れないものは「未取得」として空けろ。** 埋めた代用値は静かに正しく見える。**欠損は気づかれるが、間違った値は気づかれない。**
- **指標を足すときは「何を判定しないか」も同時に決めろ。** サンプルが足りないうちに閾値を置くのは、6/27 に「逆イールドが常態だった記憶」で早鳴りしたのと同じ失敗の別形態。**出すこと**と**決めること**は分けられる。
- **差分には窓を、スプレッドには符号規約を、名前に埋めろ。** 窓の無いΔと、コメントだけ逆順の符号は、どちらも**数値が正しいまま読み手を誤らせる**。
- **★観測が観測になっているかを最初に問え。** 取得時刻の揃っていない値を並べて「変化」として読むと、**存在しない現象を観測**してしまう。日次変動が1〜3bpの指標では、**変化の大半が時刻差**になりうる。**系列は同一時刻・同一ベンダーで揃えて初めて系列になる。**（2026-08-09 追記 → §8(e)）
- **誤差源が複数畳み込まれた表から診断を出すな。** 時刻差・ベンダー差・引き算ミスが混ざった4点から「フィード依存」と結論づけたが、**純粋なベンダー差の比較は n=1** だった。**分離してから名前を付けろ**——早すぎる診断は、使える指標の芽を閉じる。
- **窓の長い指標で当日を判定するな。** 週次/30日Δは事後の記録であって、イベント当日の反応には答えない。かといって当日に1回読んで水準を出すのも足りない（他のどの値とも比較できない）。**求めているのが変化なら、同一日・同一チャートのセッション内前後比較で取れ。** 時刻差もベンダー差も入らない。
- **★代理指標を立てる前に、本体が取得可能かを先に確認しろ。** 10s30s も原油も、**`T5YIE` が無料で取れることを確認せずに**代用していた。代理は「本体が取れないとき」の手段であって、「本体を探さなかったとき」の手段ではない。（2026-08-20 追記 → §8(f)）

### (f) 測りたいものを測らず、相関があると思い込んだ別のものを測っていた（2026-08-20 / ボス指示）

(a)〜(e) で剥がしてきた層の、**さらに一段下**があった。

年輪候補 **8-2**「金の上昇には *ドル安 かつ BEが崩れないこと* の両方が要る」——この**第二条件が、一度も実測されていなかった**。代理を2回立て、2回とも失敗している。

| 代理 | 使用期間 | 結果 |
|---|---|---|
| `10s30s` | 8/4〜8/13 | 反例2件（**8/5に金が週最大の上昇をした日に縮小**、8/13に拡大したが金は無反応）→ **破棄済み**（→ (e)） |
| **原油（WTI）** | 8/19 | 「原油85.15だからBE健在」と判定 → **同日公表のFOMC議事録が否定** |

8/19公表の 7/28-29 FOMC議事録・マーケットデスク報告：

> 中東情勢の緊迫で原油価格は期間中に上昇して終わった。資産クラス横断では、**インフレ補償は原油高に対してほとんど動かず**、名目金利は主に政策金利見通しの上昇によって上昇した。近期のインフレ補償は6月FOMC後に大きく低下し、その後**原油の急騰にもかかわらず小幅にしか戻らなかった**。

**原油とBEは連動していない。** 原油をBEの代理に使うのは、10s30s を使ったのと同じ誤りだった。

**そして最も痛いのは、本体が無料で取れたということである。** `T5YIE`（5年ブレークイーブン）は FRED から認証なしで CSV が返る。**代理を2つ立てる前に、本体が取れるかを一度も確認していなかった。**

> **代理は「本体が取れないとき」の手段であって、「本体を探さなかったとき」の手段ではない。**

**層の全体像はこうなった:**

> 名前 → コメント → 窓 → 適用範囲 → 観測の取り方 → **観測対象そのものの取り違え**

(e) は「**観測が観測になっていなかった**」（同じものを、揃わない条件で測っていた）。(f) は「**そもそも別のものを測っていた**」。**(e) より一段手前**である。

**対処（2026-08-20 実装）**: `FRED_SERIES` を **Yahoo とは別の辞書・別のフェッチ経路**として新設し、`T5YIE`（近期）と `T5YIFR`（5y5yフォワード＝エネルギーの影響を剥いだアンカー）の**2本**を取る。2本なのは**差が診断になる**ため——5Y BE だけ動いて 5y5y が動かなければ市場は原油の影響を一時的と見ており、両方動けばインフレ期待そのものが動いた。8-2 が問いたいのは後者なので、1本では判別できない。

**ただし判定はしない。** レジームラベルにも複合スコアにも混ぜず、閾値も置かず、原油との相関も自動計算しない。**サンプルがゼロの指標に判定させると、判定が実測より先に固まる**——それは 8-2 で 2 回やった失敗そのものである。

**FRED は Yahoo より1日古い**（公表ラグ）ので、値には必ず `as_of` を添える。これを黙って同じスナップショットに並べれば、**(b)〜(e) で7回直した「測定窓の不一致」を、今度は機械に焼き付ける**ことになる。

**初回実測（2026-08-19 / この年輪を書いた日の1営業日前）**:

| 日 | 5Y BE | Δbp | 5y5y BE | Δbp | 金(GC=F) | WTI |
|---|---|---|---|---|---|---|
| 8/18 | 2.27 | +2.0 | 2.33 | +2.0 | 4,366.0（−1.17%） | +0.52% |
| **8/19** | **2.28** | **+1.0** | **2.32** | **−1.0** | **4,575.5（+4.80%）** | **−0.51%** |

★ **金が +4.80% 上げた日に、BE はほぼ動いていない**（5Y +1.0bp は同週の日次変動 −3〜+3bp の範囲内、5y5y はむしろ −1.0bp）。**n=1 だが、8-2 の第二条件は「効いていた」より「不要だった」側を指している。**
