## 1. 週末時点のマクロ地合い

先週の相場を一言でまとめると「**AI/クラウド決算による株の復活 × 原油高と長期金利上昇というインフレ再燃リスク × 円買い介入**」の三つ巴。

FOMC（7/28-29）は政策金利 3.50-3.75% を **5会合連続据え置き**。ただし採決は 9対3 で、カシュカリ・ハマック・ローガンの3名が **「利上げ」方向に反対票**を投じ、新議長 Kevin Warsh はフォワードガイダンスを絞る方針を示しており、市場は指標一発ごとにボラティリティが出やすい構造に変わっている。金曜時点の FF 金利先物は **9月利上げ確率 約64%**。コアPCE（6月）は前年比 +3.3%。

一方で債券市場の反応は「**ツイスト・スティープナー**」。短期ゾーンが低下し、長期ゾーンが上昇するという歪んだ形で、これは「Fedは本気で連続利上げする気がない」というマーケットの疑念（＝インフレ抑制の信認低下）を示すものだ、というのが債券ストラテジストの読み。

株式は Microsoft（FCF・クラウド見通し）と Amazon（4年超ぶりのクラウド成長率）が牽引し、SOX指数 +8%、サムスン営業利益は前年比で桁違いの増益、メモリ需要は2029年まで、という強気材料が連鎖。韓国ではレバレッジETFの段階的縮小要請＝投げ売り一巡が意識され、KOSPI は +17.91% の記録的リバウンド。日本ではキオクシアが売買代金 約3兆6,953億円という歴史的出来高でストップ高、5月の窓埋め完了。

為替は木曜に**日本の円買い・ドル売り介入**（NY時間、USD/JPY 163→158、円は最大3.3%急騰。ドルは2023年1月以来最大の日次下落）。金曜には**米財務省が複数行に「待機」を通告（レートチェック）**。EBSのスポット円出来高は10年ぶり、CME先物出来高は過去最高（CME Group）。

日銀は政策金利 **1.00% 据え置き**。ただし内容は明確に**タカ派ホールド**で、① **高田委員が利上げを主張して反対票**、② 声明で**「基調的インフレが2%目標を上回って推移するリスク」を初めて明示**、③ 植田総裁が会見で「2026年度下期からCPIは2%を明確に上回る」「多くの委員の物価見通しは高め、リスクは上方に偏る」と発言。スコシアバンクは「**9月会合での引き締めに非常に開かれたタカ派ホールド**」と評価、ロイター調査は**年内1.25%**、MUFGは**9月＋2027年1月**を予想。

ただし MUFG のスコアリングでは会見のタカ派度は 23.3（前回17.0）にとどまり、「**近い将来の利上げを積極的に織り込ませるようなフォワードガイダンスはなかった**」。介入直後だけに、より強い言葉を期待した向きには不足だった——これが金曜に円が戻された一因。

## 3. 市場別 GM 戦略

### 米国株（S&P500 / NAS100）

週足 S&P500 は 7,480.59（+0.89%、高値 7,518.61／安値 7,299.55）で引け。4H足では 7,300割れの底から V字で戻し、**7,469 / 7,493 のライン上を回復**。NAS100（US100）は 28,166.1、週足で 26,980 まで突っ込んでからの戻り。

テクニカル要所：
- S&P500 → 上値 **7,493 → 7,518（週足高値）**、下値 **7,469 / 7,410 / 7,200**
- NAS100 → 上値 **28,548 → 28,869**、下値 **28,273 / 27,931 / 27,707 / 27,465 / 26,987**

見立ては「NAS100 は昨日上げすぎたので、**28,500 方向への上昇を一旦こなした後、28,700〜28,800 をヒゲで貫通してから 28,280 へ調整**」、また下方向では「**27,800 → 28,160 の反発は取れるが大きくは描けない（＝ダマシで下げる可能性が残る）**」S&P500 は 6月2日の史上最高値から約1.6%下の位置にあり、**戻り高値圏でのレンジ**という認識が実勢に近い。

**GM戦略メモ**：week頭は決算モメンタムで上、ただし追いかけ買いは不利。NAS100 は 28,500〜28,800 が売り手優勢ゾーン、28,000割れ〜27,700 が拾い場という「レンジ内往復」の設計が素直。**NFP と 10年金利 4.75%超えが上値を潰す最大のトリガー**なので、ここを越えた瞬間にロング目線は一旦停止するのが安全。

### 日本株（日経平均）

キオクシアの歴史的出来高＋窓埋め完了＋サムスン決算＋韓国の売り枯れ、と材料が揃った状態でのスタート。整理としては「**6万円を割り込むまでは上昇相場**」という大枠で、**6万5,500円周辺からの下落の流れ（→6万4,500円をやや下回る水準）** を短期の調整レンジとして想定できる。米株と違い、日経は「反発を大きく描ける＝押し目の信頼度が高い」という差別化が顕在化している。

物色対象として売買代金上位（キオクシア、アドバンテスト、東京エレクトロン、トヨタ、太陽誘電、ソフトバンクG、日経レバETF、三菱UFJ、イビデン等）が挙げられ、売番単元での資金効率上は **日経レバETF や半導体系ETF** で代替する案もあり。

**GM戦略メモ**：月曜は「ズドンと上がって、グンと調整して終わる」ギャップアップ型を想定。**寄り天リスクが高いので飛びつかない**。押し目は 6万4,500円前後、上値の利確ゾーンは 6万5,500円前後。円高進行は輸出株の重石なので、**ドル円の介入タイミングと日経の上値は逆相関**で見ること。

### ドル円（USD/JPY）

週足は **157.469（-3.88%）**、高値 163.950 → 安値 157.238 という激しい陰線。4H足の最終足は 159.369 で始まり 157.245 まで急落しており、**金曜終盤にもう一段の当局対応があった形**（NY市場のヘッドライン上は 159.16 前後で推移していたため、その後の下押し）

テクニカル要所：**161.013 / 160.213 / 158.890 / 158.551 / 158.287 / 158.185 / 158.003 / 157.965 / 157.219 / 157.157**。上位では 162.674・163.996 が週足の壁。

「**金曜と月曜は上がっても売り**、**161円付近＝0.5戻し（跳ね戻し）＝売りゾーン**」「**火曜以降はドル買いに戻る**（9月Fed利上げ観測、有事のドル買い、実需の輸入ドル買い、新NISAの米株投資フロー）」というもの。

この「3営業日」は当局の行動可能期間を縛るルールではなく、**IMFのエピソード計数の慣行**（3営業日以内の介入は1回の市場操作としてカウント）である。ただし帰結は同じで、7/30(木)起点なら 7/31(金)・8/3(月) までは同一エピソード＝追加介入しても回数が増えない。**8/4(火)以降の新規介入は4回目**となり、6ヶ月3エピソードの free-floating 分類を逸脱する。**日本はこれで枠を使い切った**（4/30-5/1＝1回目、5/6＝2回目、7/30＝3回目。1回目がルックバックから外れるのは10月末）。

レートチェックの背景として報道で確認できるのは、**米財務省が複数行に「介入の可能性があり今後の行動に備えよ」と通告**（ロイター）、**ベッセント財務長官が「円は非常に過小評価されている」と公言**、**三村財務官が「米国から心理的支援を超える支援を受けている」と述べた**こと。ロイターは一連を「協調介入」と明記している。**IMFの枠が縛るのは日本の分類であって米財務省の行動ではない**ため、「日本の枠切れ＝無防備」とは限らない点は8月の設計上の重要な留保。

補足として、市場サイドの評価は冷ややかで、**介入は持続的な円高をもたらさず、BOJの利上げがなければ円の見通しは改善しない**というのがストラテジストの一般的な見方。

**GM戦略メモ**：月曜は「**戻り売り優位、ただし戻りの限界は 160.2〜161.0**」。157.2 前後は介入後の安値で、ここを終値で明確に割れると 153.9 が次の視野。逆に火曜以降に 161 を明確に上抜けると介入警戒が緩んで 162.6 テストのシナリオ。**15分刻みで反発する介入特有の値動き**が想定できるため、ボラ拡大時の逆張り・順張りいずれもストップ必須。

### コモディティ ②：ゴールド（XAU/USD）

週足 **4,046.34（-0.17%、高値4,120.48／安値3,995.84）**。金曜のスポット金は -1.26% で 4,050 近辺、カナダ株を押し下げる要因にもなった。週足MACDはゼロライン下でマイナス圏、20週線を明確に下回っており、**4,651 の高値からの調整局面が継続**中。

テクニカル要所：**4,166 / 4,141 / 4,120 / 4,102 / 4,071 / 4,062 / 4,040 / 3,996 / 3,940**。

見立ては「**4,120ドル超えなら上昇、ターゲット 4,144ドル**」としつつ、「**7/23起点のトリプルトップで売り圧が強すぎる**」ため今はあまり触りたくない、という強い迷いが市場から伺える。

**今週最大の tell**：協調介入＋ハト派に読まれたFOMC＋GDP未達（Q2 +1.5%、予想2.1%）という、**ヘッドライン上は最もドルネガティブな週に、金は週足で下げて引けた**。理由は「ドル安の質」が木曜と金曜で変わったこと——木曜はDXY -0.8%で100割れの**ドル全面安**（金は4,120まで上昇）、金曜は米イラン緊張再燃と月末利確で**DXYが反発し、円だけが強い**構図に変わった。**金はDXYに追随し、USD/JPYには追随しなかった**。月末利確・換金売りは副次的で、これが構造的な理由。

**用語の精緻化**：「実質金利＝長期金利上昇」ではない。**名目 = 実質 + BE(ブレークイーブン)**であり、7/29は**実質+6bp・BE+5bpの同時上昇**＝インフレ期待でも純粋な引き締めでもなく、**タームプレミアム／ソブリン信用の再評価**の象限。この象限では金の逆風（機会費用↑）と追い風（準備資産分散）が同じ源から出るため、**方向を論理で事前に導出できずフローの量で決まる**（→ workspace/trade_brain/2026-07-30_real_be_decomposition.md）。レンジを上に破るのは「インフレが出ること」ではなく**実質金利が下がること**で、その種は Q2 GDP 1.5% の未達にある。

**GM戦略メモ**：**方向感なし＝サイズを落とす**のが最も合理的。4,120〜4,166 は明確な戻り売りゾーン、3,996〜3,940 が下値サポート帯。BOJ・Fed双方がタカ派＝**実質金利が両側から支えられる**ため上値は重い一方、ソブリン買いと原油高によるインフレヘッジ需要と地政学は下支え。**4,166 を終値で上抜けるまでは戻り売り優位**という整理が素直。ただし週足Fibo38.2（4,062）を割って引けている点で、**レンジ内のリスクは下寄り**。

## 4. シナリオ分岐（週明けの意思決定ツリー）

**メインシナリオ（確率高）**：8/10の週までは株のリバウンド継続。ドル円は月曜まで介入警戒で戻り売り、火曜以降ドル買い復帰。原油は高止まり、金利は高止まり。→ **株は押し目買い、円はクロス円含め戻り売り→火曜以降切り替え**。

**リスクシナリオA（金利主導の株安）**：NFP が上振れ → 9月利上げ確率が80%超へ → US10Y が 4.81% 突破 → NAS100 が 27,700 割れ、日経は 6万4,500円割れ。→ **原油と10年金利の同時上昇が発火点**。

**リスクシナリオB（地政学エスカレーション）**：ホルムズ海峡の封鎖度合いが上がる → WTI が 88.5 上抜け → インフレ期待急騰 → 株安・金高・ドル高（有事のドル買い）。この場合、**ゴールドだけが上記の「戻り売り優位」から反転**するので注意。

### 欠けている論点

**① NFP は 8/7(金)。介入エピソードの窓（〜8/3月）の外側に落ちる。**
これは非対称を生む。強いNFP → 9月利上げ観測強化 → ドル円上昇、が**日本が撃てない期間に起きる**。逆に言えば、市場がその日程を知っている以上、**8/4以降のドル円ロングは混雑しやすい**。boss のシナリオ「火曜以降はドル買い」は公開ルールに基づく読みで市場も同じものを見ているため、**日付エントリーではなく「当局が撃たないことを価格が証明した後」（161回復して叩かれない）を待つ**のが型と整合する。

**② シナリオDが無い：ドル全面安の継続**
本文は EUR/USD 節で「DXY 週足は 96.377 まで大きなサポート空白」と正しく指摘しているが、シナリオ分岐に反映されていない。**DXY が 99.69 を割れると、ゴールドの「戻り売り優位」は前提ごと反転する**（＝リスクシナリオBと同じ結論だが経路が違う）。木曜のドル全面安が再来する条件は、①NFP大幅未達、②米財務省のドル安容認発言の追加、③30年のさらなる上昇（信認劣化のドル安）。**ゴールドのレンジ上抜けはこの経路でしか起きない**ので、DXY 99.69 を単独の監視ラインとして持つ価値がある。

**③ 今週のレジーム上の意味**
