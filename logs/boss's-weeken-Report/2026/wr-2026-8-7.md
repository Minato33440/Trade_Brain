### 1. NFPの中身（BLS原文で確認）

**7月 非農業部門雇用者数 −23,000人**（ダウ・ジョーンズ予想 +83,000人）。動画で紹介されていた「8万人」の事前予想に対し、**増加どころか純減**という結果。

さらに深刻なのが**改定**です。5月が +129,000 → **+63,000**（−66千人）、6月が +57,000 → **+20,000**（−37千人）で、**2ヶ月合計 −103,000人の下方修正**。過去12ヶ月平均も月+34,000人まで鈍化している。

内訳は地方政府教育 −50,000、小売 −19,000、金融 −14,000（2025年5月ピークから累計 −121,000）。増加はヘルスケア +22,000のみで、それも過去平均+36,000を下回るペース。

**ただしヘッドラインの失業率は4.2%→4.1%に「低下」しました。** これは労働参加率が61.5%→**61.4%と5年超ぶりの低水準**に落ち込んだため（1月からは−0.7pt）で、「職探しをやめた人が増えた結果の失業率低下」という**質の悪い改善**。一時解雇者は+153,000人増えて921,000人。平均時給は+2セント（前年比+3.2%）でインフレ圧力は残存。

つまり **「雇用は純減、しかしインフレは高止まり」＝スタグフレーション型の最悪の組み合わせ**。CNBCが引用したWilsey Asset Managementのコメントも、FRBが**「conundrum（板挟み）」**に置かれたという趣旨。

### 2. ここが肝：「利上げ否定」ではなく「利上げ先送り」

「米金利引き上げ否定が織り込まれた」という点は、**半分正しく、半分は行き過ぎ**。

CME FedWatchベースで：
- **9月利上げ確率：約42%**（発表前から大幅に低下、50%割れ）
- **10月までの利上げ確率：57%超**（＝依然として過半数が利上げを見込む）

**利上げは「否定」されたのではなく「9月から10月以降へ後ろ倒し」されただけ**。
これを裏付けるのが債券の値動きで、US2Yは日中安値4.154%まで急低下した後、**引けにかけて4.199%まで4.5bp買い戻され（＝利回り上昇）**ている。
US10Yも4.639%まで下げた後4.649%で引け。**市場は金利低下を最後まで追いかけなかった**、というのが金曜の本質。

前回メモで「US2Y 4.230%割れ＝利上げ観測後退」と置いたが、**実際に割って4.199%で確定**。次のラインは以下に更新。

| 年限 | 金曜終値 | 下方向 | 上方向（利上げ観測復活） |
|---|---|---|---|
| US2Y | 4.199% | **4.154%（金曜安値）** → 4.10% → 4.05% | 4.245% → **4.256%** → 4.373%（52週高値） |
| US10Y | 4.649% | 4.639% → **4.629%** → 4.50% | 4.700% → 4.745% |
| US30Y | 5.202% | 5.172% → 5.10% | 5.237% → 5.28%（7/31の2007年来高値） |

**US2Yの4.154%を割るか、4.256%を超えるか**が今週すべての起点。

### 3. 各市場の修正シナリオ

**米国株：強気シナリオが「的中」した側**

NDX現物 **29,722.30（+1.19%）**、S&P500 **7,757.64（+0.62%）**、ダウ **54,036.93（+0.28%）**、ナスダック総合 **26,690.62（+1.30%）**。金利低下＝グロース株買いという素直な反応で、**「29,560超えで上昇」というトリガーは既に発動済み**。
しかもS&P500は8/6に最高値を更新し、その週は4月以来最強という地合い。

月曜以降は **29,560〜29,600を上抜けたサポート**として扱い、次のターゲットは **29,870 → 30,000 → 30,922**。29,560割れで初めて「ダマシ」を疑う構図に変わる。前回書いた「29,129割れ→28,718」シナリオは**当面棚上げ**でOK。
ただし「雇用純減＝景気減速」が意識され始めると、金利低下メリットより業績懸念が勝つ局面に反転する。**そのスイッチは8/12のCPI。**

**日本株：夜間で+640円の含み益スタート**

現物の8/7終値は **65,606.71（−0.12%）**でしたが、日経CFDは夜間セッションでNFP後に **高値66,698 → 66,248** まで買われている。つまり**月曜は600〜650円程度の上ギャップで始まる計算**。

動画が挙げた **66,340円の上抜けトリガーは夜間で既にクリア済み**で、次の焦点は **67,353円 → 67,596円**。ただしギャップアップ後の「寄り天」は日経の典型パターンなので、**寄り付きで飛びつかず、66,340〜66,000への押し目を待つ**のが定石です。66,000を明確に割り込むならギャップ埋め＝65,606（金曜現物終値）が次のサポート。

ドル円がほぼ動いていない（円高が進んでいない）ことは、日本株にとって追い風の維持を意味します。SBG・アドバンテスト主導という構図、TOPIX浮動株400億円未満除外の話は変更なし。

**ドル円：NFP後もほぼ無風 — これが一番の注目点**

**157.78（−0.64）で終了**。米金利が低下し、DXYが99.604まで売られたにもかかわらず、**ドル円だけがほとんど動かなかった**。
理由は明快で、①失業率は逆に低下して4.1%、②利上げは否定されず10月に先送りされただけ、③円側の要因（財政拡張・日銀の遅れ）が重く、介入効果が剥落中だからです。

CNBCの検証によれば、7/31の日米協調介入で163台から**155ちょうど**まで円高が進みましたが、**その値幅の半分近くを既に戻して158.50前後**に落ち着いています。BofAは当局の短期目標を「155割れ」と見ていましたが、155は一瞬タッチしただけ。ベッセント財務長官も「介入はシグナル、方向を変えるのは政策」と明言しており、PGIMのエコノミストは「介入だけで円安トレンドは反転しない、むしろ裏目に出る可能性がある」と警告している。

**結論：動画の「円安に戻りやすい」という見立ては維持されている。** ただし159.30の売りゾーンには届いていないため、レンジ上限を切り下げて運用。

| 方向 | レベル |
|---|---|
| 上値 | 158.100 → **158.50〜158.56（当面の上値メド）** → 159.20〜159.50（戻り売りゾーン） → 161.013 |
| 現値 | 157.78 |
| 下値 | 157.219/157.157 → 157.086 → **156.589** → 155.7（介入ライン） |

**157.0〜158.5のレンジ想定**で、上限で売り・下限で買いの往復。156.589割れで介入警戒モードに切り替え。

**ゴールド：ここが最大の修正点 — 想定を大幅に超えて上放れ**

現物 **4,342.41（+103.18／+2.43%）**、日中高値 **4,370.49**。
動画のターゲット4,288と抵抗帯4,290はあっさり突破され、日足の抵抗 **4,302.18 も上抜け**ました。7週間ぶりの高値圏。

上昇の理由は3つ重なっています。
①**雇用純減＋インフレ高止まり＝スタグフレーション懸念**（金の最も好きな環境）
②**ドル安**（DXYは6週ぶり安値圏）
③**ホルムズ海峡再開に向けたイラン=オマン交渉進展**によるリスク資産全般の改善と、それに伴う原油下落（金は原油と逆相関で推移してきた経緯あり）。
加えて中国など中銀の継続買いという構造要因。

一方で**金は今年1/29の史上最高値5,585〜5,589から依然20%以上下**にあり、日足の大きな下降チャネルの中の戻りである点は忘れてはいけない。

| 方向 | 修正後レベル |
|---|---|
| 上値 | **4,370.49（金曜高値・最初の壁）** → 4,380.85 → 4,400 → 4,651.26 |
| 現値 | 4,342.41 |
| 下値 | 4,302.18（旧抵抗→新サポート、ここを守れるかが試金石） → 4,248.25 → 4,216.34 |

**戦略：4,302.18を上抜けサポートとして機能させられるかを確認しつつ押し目買い。** 4,302割れなら「一日限りの過剰反応」と判断して4,248まで撤退。動画の「金銀はコツコツ買い集め」という中長期スタンスは、今回の値動きで説得力が増した。

**WTI：動画の上昇シナリオは不成立、ターゲットを反転**

**77.08（−0.21）**、日中高値78.77・安値76.53、**週間で−8.96%**。動画は「中東情勢悪化」を理由に79.50への上昇を見ていたが、**実際に進んだのは逆の「イラン=オマンによるホルムズ海峡再開合意が近い」という緩和ニュース**。「イラン情勢は緩和と悪化が毎日入れ替わる」というTACOトレードのリスクが顕在化した形。

- 上値：78.77（金曜高値） → 79.762 → 82.749
- 下値：**76.705（重要／割れると加速）** → 74.899 → 70.00

**戦略：79.50ターゲットの上目線は一旦破棄。76.705の攻防を見て方向を決める。** ホルムズ再開が正式合意なら70ドル方向、交渉決裂なら一気に82.749まで戻す、というヘッドライン主導の二極化相場。**持ってもポジションは軽く。**

### 4. 今週の勝負どころ：8/12(水)の米CPI

金曜の値動きは「利上げ先送り」を織り込んだだけで、**方向を決めるのは物価指標**。確定スケジュール（BLS一次情報）：

- **8/11(火)** 日本は山の日で休場（お盆の薄商い本格化）
- **8/12(水) 21:30 JST** — **米7月CPI** ← 今週最大のイベント
- **8/13(木) 21:30 JST** — 米7月PPI
- **8/28(金)** — BLSの年次ベンチマーク改定の速報値（QCEW準拠）。**過去1年の雇用者数が大幅に下方修正されるリスクイベント**として今から意識しておく価値がある

**分岐**：CPIが強ければ「雇用は減っているのにインフレは下がらない」＝10月利上げ確率が70〜80%へ上昇し、株安・ドル高・金は板挟み。CPIが弱ければ利上げ観測がほぼ消滅し、株・金の同時上昇、ドル安・ユーロドル1.16へ。**どちらに転んでもボラティリティは金曜より確実に大きくなる。**
