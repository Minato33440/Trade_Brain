## 50.985の正確な接続

前週末:

```
旧キャンペーン 129.000 + 新キャンペーン確定 147.500
+ 新キャンペーン含み (4,431.07 − 4,311.00) × 0.5 = 60.035
= 336.535
```

当週末:

```
累計実現 372.885 + 残玉含み 9.050 = 381.935
週間通算増分 = 381.935 − 336.535 = 45.400
```

したがって:

```
当週実現 96.385 − 週間通算増分 45.400 = 50.985
前週含み 60.035 − 当週末含み 9.050 = 50.985
```

前週含みの一部は9/7の+42.500として実現したが、新々キャンペーンに当週末+9.050の含みが残る。よって「前週の含み益が実現化した分」は方向としては近いものの、差額そのものを説明するなら「**未実現PnLが+60.035から+9.050へ50.985減少したため**」と書くのが正確である。
